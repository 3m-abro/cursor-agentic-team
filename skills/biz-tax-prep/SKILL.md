# BIZ — Tax Prep

**Department:** BIZ

**NEW** document-organization procedure for tax season.

> **Disclaimer:** Not tax or legal advice. Checklist / organizer only — a qualified tax professional must advise and file.

## Inputs

Entity type, jurisdiction(s) if known, fiscal year, prior return summary if any, book exports.

## Procedure

1. Build document checklist (income, expenses, assets, payroll, prior filings) — mark provided vs missing.
2. Timeline to filing deadline (user-supplied or "confirm with tax pro").
3. Question list for the CPA / agent (ambiguous classifications, owner draws, cross-border).
4. Never invent jurisdiction-specific deductions, rates, or filing rules as fact.
5. Hand finance packs to `finance-financial-statements` / `finance-audit-support` as needed.
6. HIGH uncertainty → escalate human tax pro.

## Output

Organizer checklist + open questions. No estimated tax liability presented as authoritative.
