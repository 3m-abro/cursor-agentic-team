# FINANCE — Audit Support (Auditor Prep)

**Department:** FINANCE

**NEW** procedure. Prefer canvas for PBC trackers.

> **Disclaimer:** Not legal or financial advice. Does not constitute an audit, review, or assurance opinion.

## Inputs

Auditor request / PBC list, period, entity, available systems/docs.

## Procedure

1. Parse requests → inventory of evidence items with owners + due dates.
2. Map each item to source system / folder; mark gaps.
3. Draft walkthrough narratives (process → control → evidence) without overclaiming.
4. Prepare sample selection helpers only when population data provided.
5. Escalate HIGH risk / control failures to human + LEGAL if compliance-related.
6. Canvas: PBC tracker (status, link, blocker).

## Output

PBC tracker + gap list + questions for management. Never invent sample results.
