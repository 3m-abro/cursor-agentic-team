# FINANCE — Journal Entry (Journal Keeper)

**Department:** FINANCE

**NEW** procedure. Prefer canvas for JE tables.

> **Disclaimer:** Not legal or financial advice. Draft bookkeeping aid only — accountant must approve before posting to live books.

## Inputs

Date, entity, narrative/facts, amounts, accounts (or chart), tax codes if any.

## Procedure

1. Restate economic event in one sentence.
2. Identify debit(s) and credit(s); amounts must balance.
3. Pick accounts from provided CoA; if missing, propose names marked **PROPOSED**.
4. Attach memo + supporting doc refs.
5. Flag unusual entries (related party, large round, prior-period) for review.
6. Deliver JE table in **canvas**.

## Output format

| Date | Account | Debit | Credit | Memo |
|------|---------|-------|--------|------|

Balance check line mandatory.
