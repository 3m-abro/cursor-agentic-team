# MARKETING — Lead Magnets

**Department:** MARKETING

Thin **NEW** procedure. No upstream single skill; compose from research + copy + design handoffs.

## When

Need email/contact capture with a clear value exchange — not a full product.

## Procedure

1. **Goal** — list growth vs. sales-qualified leads; one primary KPI.
2. **Audience** — run or reuse `marketing-customer-research` brief (ICP + language).
3. **Offer pick** (one format):
   - Checklist / cheat sheet (fast)
   - Template / swipe file (high perceived value)
   - Mini-guide / one-pager (authority)
   - Calculator / interactive tool (hand DESIGN + DEV)
4. **Promise line** — specific outcome in ≤12 words; no vague "ultimate guide".
5. **Outline** — 5–9 sections max; each section = one actionable win.
6. **Copy** — `marketing-copywriting` for landing + thank-you + email drip skeleton.
7. **Page CRO** — `marketing-cro` for form friction, social proof, above-fold promise.
8. **Visual** — DESIGN: `design-frontend` / `design-brand` / `design-web-artifacts` as needed.
9. **Delivery** — PDF/Notion/Canvas delivery path + confirmation email body.
10. **Measure** — define conversion event + 1 follow-up experiment.

## Quality bar

- Solves a painful sub-problem of the paid offer (not a random tip dump).
- Readable in <10 minutes OR usable as a reusable template.
- CTA after delivery points to next step (demo, trial, booking).

## Do not

Ship 40-page ebooks. Prefer sharp assets that convert.
