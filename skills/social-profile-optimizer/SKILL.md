# SOCIAL — Profile Optimizer

**Department:** SOCIAL

**NEW** procedure. No upstream profile skill on scaffold host.

## Inputs

- Platform(s), current bio/headline/banner, ICP, offer, proof assets, voice guide (or run `social-voice-builder`).

## Procedure

1. **Audit** — clarity of who / for whom / outcome in ≤3 seconds.
2. **Headline / name line** — outcome + audience; kill jargon.
3. **About / bio** — problem → proof → offer → CTA; platform char limits.
4. **Visuals** — headshot + banner brief; hand DESIGN (`design-brand` / `social-youtube-thumbnail` patterns for banners).
5. **Pinned / featured** — 1–3 assets that prove the promise.
6. **Links** — one primary destination; UTM if measurable.
7. **Keywords** — searchable terms for platform discovery (LinkedIn skills, X bio keywords).

## Output

Before/after copy + checklist of visual/link fixes. Score each field 1–5 with one fix.

## Do not

Keyword-stuff. Profile is positioning, not a resume dump.
