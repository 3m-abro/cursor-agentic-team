# LEGAL — Vendor Check

**Department:** LEGAL

**NEW** vendor diligence checklist.

## Hard rules

1. **Not a lawyer.** Not legal advice.
2. **HIGH risk → escalate human counsel / security.**
3. **Never invent jurisdiction-specific law as fact.**

## Inputs

Vendor name, service, data shared, contract/DPA if any, security docs if any.

## Procedure

1. Data map: what personal/secret data leaves the org.
2. Checklist: DPA/ToS, subprocessors, breach notice, retention, audit rights, insurance, exit/export.
3. Security: SOC2/ISO claims — verify docs provided; do not assume.
4. Score blockers vs nice-to-haves; recommend negotiate / accept / reject.
5. Pair with `legal-review-contract` / `legal-compliance-check` when docs available.

## Output

Diligence scorecard + open asks for vendor / counsel.
