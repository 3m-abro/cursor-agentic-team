# SOCIAL — Reels Scripting

**Department:** SOCIAL

**NEW** procedure for vertical short-form scripts.

## Inputs

Topic, platform, length (15/30/60s), offer/CTA, proof, brand voice.

## Procedure

1. **Hook (0–3s)** — pattern interrupt; 3 hook options via `social-hook-generator`.
2. **Promise** — what viewer gets by end of clip.
3. **Beats** — 3–5 spoken beats; one visual action per beat (B-roll / text on screen).
4. **Proof** — number, demo, or micro-story in middle third.
5. **CTA** — single action (follow, comment keyword, link in bio).
6. **On-screen text** — max ~6 words/line; readable on mute.
7. **Caption** — platform caption + 3–5 hashtags max (or brand set).

## Output format

```
HOOK:
BEAT 1 (0–XXs): VO / VISUAL / TEXT
...
CTA:
CAPTION:
```

## Quality bar

Mute-test: story still lands from on-screen text alone.
