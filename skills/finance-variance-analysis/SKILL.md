# FINANCE — Variance Analysis (Variance Analyst)

**Department:** FINANCE

**NEW** procedure. Prefer canvas for bridges and heatmaps.

> **Disclaimer:** Not legal or financial advice. Analytical commentary only.

## Inputs

Actuals, budget/forecast/prior, period, materiality threshold (default 5% or absolute floor user sets).

## Procedure

1. Compute $ and % variance by line.
2. Separate volume / rate / mix / timing / one-offs when data allows.
3. Rank material variances; write 1–2 sentence drivers each (fact-based).
4. Flag unexplained gaps — ask for data, do not invent causes.
5. Canvas: variance table + waterfall/bridge + narrative bullets.

## Output

Top-N variances with drivers + questions for ops owners.
