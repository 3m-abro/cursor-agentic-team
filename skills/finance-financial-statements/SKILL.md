# FINANCE — Financial Statements (Statement Builder)

**Department:** FINANCE

**NEW** procedure. Prefer Cursor canvas for tables and statement layouts.

> **Disclaimer:** Not legal or financial advice. Educational / operational draft only — verify with a qualified accountant before decisions.

## Inputs

Period, entity, chart of accounts / trial balance / export, currency, reporting basis (cash vs accrual if known).

## Procedure

1. Confirm period + basis; list missing source docs.
2. Build **P&L** (revenue → COGS → gross → opex → operating → net).
3. Build **Balance sheet** (assets = liabilities + equity); flag imbalance.
4. Build **Cash flow** (ops / invest / finance) if cash movements available; else note gap.
5. Annotate material lines; link to journal sources when present.
6. Render primary deliverable in **canvas** (statement tables + variance callouts).

## Output

Three statements (or available subset) + imbalance/gap list. No invented balances.
